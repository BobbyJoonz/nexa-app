# Definition of Done — قانون پایان کار (سخت‌گیرانه)

> این سند معیار «پذیرفته‌شدن» است. هیچ تغییری «تمام» نیست مگر همهٔ بندهای زیر روی
> **همان کامیتِ نهایی** (نه «آخرین وضعیت») رد شوند. نسخهٔ مرجع: `master`.

## ۰) قبل از شروع هر آیتم — «پذیرفته‌شدن یعنی چه؟»

هر درخواست باید پیش از کدنویسی به اجزای اندازه‌پذیر تبدیل شود. ممنوع: صفت‌های سلیقه‌ای
(«غنی‌تر»، «بهتر»، «حرفه‌ای‌تر»). الگو:

| درخواست سلیقه‌ای | تبدیل‌شده به معیار اندازه‌پذیر |
|---|---|
| «توضیح هر دکمه خیلی کم است» | هر نقطهٔ آناتومی ≥۳ گام بازرسی دوزبانه + بنر ایمنی روی قطعات پرخطر (اینواریانت در `validate-content` و تست) |
| «بخش کار نمی‌کند» | گیت‌های بیلد بر روی همان commit + تست رفتاری مشخص |

## ۱) چک‌لیست DoD — همه باید ✓ باشند

- [ ] معیار پذیرش نوشته و تأیید شد (قبل از شروع)
- [ ] فقط روی یک شاخه؛ ادغام به `master` فقط **پین‌شده به کامیت** (`git merge <hash>`) — هرگز ادغامِ tipِ متحرک شاخه‌های خارجی
- [ ] هر متن کاربر-دید دوزبانه (en/fa) و بدون نشت سایتیشن (منبع/صفحه/دفترچه) — گیت grep
- [ ] رفتار جدید ≥۱ تست رگرسیون دارد؛ شمار تست‌ها هیچ‌وقت کم نمی‌شود (خط مبنا: **۱۰۷**)
- [ ] گیت‌های محتوا روی همان commit: `pnpm validate:content` · `pnpm check:translations` · `pnpm check:links`
- [ ] گیت‌های بیلد روی همان commit: `pnpm test` (vitest) · `export:android` · `export:ios` · موبایل `tsc` (بعد از exportها) · وب `next build`
- [ ] درخت کاری تمیز؛ هیچ فایل حسابرسی (`.qa*.txt`, `.e.txt`, `.off.txt`, `.d*.txt`, `.final*.txt`) کامیت نشده (هوک pre-commit بلوک می‌کند)
- [ ] محیط: بدون `pnpm-lock.yaml` سرگردان خارج از ریشهٔ ریپو؛ دستورها با شیم `tools/pnpm`
- [ ] خروجی روی `master` ثبت و قابل‌بازتولید

## ۲) قواعد تکیه‌گاه (سخت)

1. **دو نویسنده ممنوع:** اگر فرایند/نشست دیگری هم‌زمان روی همین شاخه کامیت می‌زند، این وضعیت
   خودش یک بلاکر DoD است — آیتم را متوقف کن، نویسندهٔ دوم را ببند، بعد ادامه بده.
2. **نکشیدن tip خارجی:** کامیت‌های شاخهٔ `feat/rtl-refactor-finish` فقط با هشِ دقیق و پس از
   گیت کامل وارد `master` می‌شوند. کامیت‌های ناخواستهٔ آن شاخه هرگز مستقیم ادغام نمی‌شوند.
3. **کی‌استور:** هر بیلد انتشار باید با همان `credentials/nexa-upload.jks` امضا شود؛ بکاپ
   دوم همیشه در `C:\Users\Lenovo\nexa-keys\backup\` (خارج از گیت). گم‌کردن کلید = پایان پروژه.
